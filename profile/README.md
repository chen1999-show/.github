# ✨ 个人/外包项目集成

## 🛠️ 快速开始

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发服务器
```bash
npm run serve
```

### 3. 构建生产版本
```bash
npm run build
```

node版本：18.x 以上

---

## 📝 注意事项

1. **Node.js 版本**：请确保使用 Node.js 16.0 或更高版本
2. **包管理器**：项目使用 npm 或 yarn
3. **开发环境**：推荐使用 Webstorm / VSCode 并安装相关插件
4. **浏览器支持**：支持现代浏览器，不支持 IE

## 🔐 Git 贡献提交规范

参考规范
- `feat` 增加新功能
- `fix` 修复问题/BUG
- `style` 代码风格相关无影响运行结果的
- `perf` 优化/性能提升
- `refactor` 重构
- `revert` 撤销修改
- `test` 测试相关
- `build` 影响构建系统或外部依赖的更改
- `docs` 文档/注释
- `chore` 依赖更新/脚手架配置修改等
- `workflow` 工作流改进
- `ci` 持续集成
- `types` 类型定义文件更改
- `wip` 开发中

```
例： feat(login): 添加用户登录功能
```
